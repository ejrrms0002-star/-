# YTH-UP 전체 교체 최종본

이 ZIP의 최상위에 있는 모든 파일 및 `assets/` 폴더가 완전한 배포 세트입니다. ZIP 파일이나 최상위 폴더를 그대로 저장소에 업로드하지 않고 **압축을 푼 폴더 안의 내용**을 GitHub 저장소 최상위에 업로드하세요.

- `index.html`, `about.html` 외 HTML 9개: 각각 독립 메뉴 페이지
- `assets/images/`: 갤러리·뉴스·후기 사진
- `assets/profiles/`: 강사진 이미지 (원본에 없던 두 사진은 중립적 SVG 대체)
- `assets/logos/`: 공통 로고와 소개 페이지 중앙 로고
- `CNAME`: www.yth-up.co.kr 연결. **삭제 금지**

`about.html`의 4단계 카드: 가운데 정렬, 은은한 머스터드 STEP, 그림자와 호버 효과 적용.

**주의:** GitHub 기존 저장소를 백업한 후 기존 파일을 삭제하고 이 ZIP의 내용만 추가할 수 있도록 로컬 참조 파일 존재 여부를 검사했습니다. 업로드 후 GitHub Pages 배포까지 수 분 걸릴 수 있습니다. 일부 서브페이지는 Tailwind CSS CDN과 Lucide CDN, Google Fonts 등 외부 서비스에 의존하므로 인터넷이 연결되어 있어야 디자인과 아이콘이 완전히 표시됩니다. 상담 폼의 실제 접수 기능 등 서버 기능은 별도 확인이 필요합니다.
