YTH-UP 전 페이지 디자인 통일판

증상: 새 헤더 아래 서브페이지에 기존 WITH ACADEMY/그린 클래스 디자인과 로고가 잔존.
수정: 9개 HTML 모두 기존 CSS 뒤에 공통 최종 테마를 내장했습니다. 메인과 서브페이지에 동일 헤더/로고/색상 적용. 소개 페이지의 기존 그린 클래스 제목을 YTH-UP 소개에 맞게 변경. 본문 카드/뉴스/갤러리/강사진 기능은 최대한 유지.

업로드 순서
1. ZIP 압축 해제.
2. GitHub youth 저장소의 main 브랜치 루트에 HTML 9개와 ythup-logo.png 업로드하여 같은 이름 파일 교체.
3. ythup-design.css도 같이 업로드(선택사항: HTML에 스타일이 내장되어 즉시 적용됨).
4. txt, README 파일은 GitHub에 올리지 않아도 됨.
5. 기존 사진·동영상·CNAME은 삭제하지 마세요.
6. Actions 배포 완료 후 Ctrl+Shift+R.
7. 실제 상담 접수 연동은 이 디자인 파일만으로 새로 제공되지 않습니다.
