YTH-UP 신규 2D 로고 반영 · 전체 사이트 교체본

포함: HTML 9개, 각 HTML의 전체 복붙용 TXT 9개, ythup-design.css, 가로형 로고 ythup-logo.png, 원형 세로 로고 ythup-logo-full.png.

GitHub 적용 (가장 쉬운 방법)
1. ZIP 파일을 압축 해제합니다.
2. github.com/ejrrms0002-star/youth → main 브랜치 → Add file → Upload files
3. 압축 폴더 최상위의 .html 9개, .css 1개, .png 2개만 선택하여 업로드하고 Commit changes 합니다.
4. 기존 이미지, 동영상, CNAME 파일은 삭제하지 마세요.
5. Actions에서 배포 완료를 확인한 뒤 Ctrl+Shift+R 새로고침합니다.
6. HTML을 수동 교체한다면 각 *_복붙용.txt 파일을 열어 Ctrl+A/C 후 해당 .html 파일 코드 전체를 바꿉니다. 그래도 PNG 파일 2개는 따로 업로드해야 합니다.

주의: 이 자료는 직전 '전체 페이지 디자인 통일판'을 기반으로 로고를 교체했습니다. 온라인 GitHub 저장소에 이 시점 이후 별도 편집하신 내용은 ZIP 안에 자동 반영되지 않습니다. 상담 신청 실전 전송 기능을 새로 연결하지 않았습니다.
